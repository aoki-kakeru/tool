Sheet Extractor / シート抽出機

esm Developers の JS プラグイン API ドキュメント（クラスページ）の HTML ソースを貼り付けると、インスタンスプロパティとインスタンスメソッドを TSV に自動抽出します。

0 クラス ・ 0 行

1. HTML ソースを貼り付け

対象クラスのページ（例 /js-plugin/class/abstract/SheetItem.html）を開き、右クリック →「ページのソースを表示」→ 全選択してコピーしたものをそのまま下に貼り付けてください。<head>やスクリプトタグが混ざっていても問題ありません。

2. 抽出結果

サンプルデータを表示中です（SheetItem / SingleSelectItem）。自分のデータを貼り付けると自動で追加されます。

TSV（コピー用）

貼り付けたHTMLはこの画面内だけで処理されます（外部送信なし）。抽出結果はこのブラウザにのみ保存されます。
